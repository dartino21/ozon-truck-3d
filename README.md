# OZON — интерактивная 3D-модель фургона

[Открыть модель](https://dartino21.github.io/ozon-truck-3d/)

Вращение и приближение модели, четыре независимо открывающиеся двери, готовые ракурсы, сохранение PNG и экспорт GLB с анимациями.

Статическая страница без внешних зависимостей. Все изображения и библиотеки встроены в `index.html`.

Модель — приближённая визуальная реконструкция по фотографиям. Размеры, скрытые детали и интерьер упрощены. Оформление OZON перенесено с предоставленных изображений.

Three.js распространяется по лицензии MIT; см. THIRD-PARTY-LICENSE.txt.
